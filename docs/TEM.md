# Learning reusable structure with TEM

TEM separates a cognitive map into reusable structure **g** and sensory identity **x**.
Their conjunction **p** binds what was observed to the inferred structural location.
A fast Hebbian memory **M** stores these conjunctive patterns within each world.
Slowly trained weights learn transitions shared across worlds; memory resets between worlds.
This lets a model predict a previously seen observation through a new route in a new world.

```text
 action -> g -> p <- x
               | ^
               v |
                M    (Hebbian storage and attractor retrieval)
```

## Run and inspect

From the repository root, with the package and development dependencies installed,
run these three commands:

```bash
python -m pytest tests/tem -q
python examples/tem_whittington.py --steps 400
python experiments/tem_overnight_report.py
```

Measured wall times on this Mac: 29.23 s, 9.07 s, and 1.26 s respectively.
These measurements overlapped other validation jobs; they are approximate run costs.
The short example checks execution, not the overnight training result.
The report aggregates supplied JSON records; it does not retrain models.
The spiking example (`python examples/spiking_tem_kawahara.py`) took 57.69 s.
Its theta oscillation is imposed, and its small run is not a paper reproduction.

## Four changes that stabilized training

- **Missing L_p_x and mis-scaled objective:** supervising sensory-cued memory and
  calibrating loss reductions restores the intended balance between reconstruction,
  latent consistency, and activity costs.
- **Reliability-blind fusion → reliable_fusion:** memory correction is weighted by
  retrieval reliability so an unreliable recalled pattern does not overwhelm path integration.
- **Unbounded attractor → bounded activation:** bounding recurrent retrieval prevents
  growing activations from destabilizing memory and gradients.
- **Compressed memory curriculum:** gradually increasing memory use lets sensory
  compression and transition learning develop before full associative retrieval is required.

These are implementation choices tested here, not four independently established causal
results: v1 groups objective and activation changes; v2 adds reliability-aware fusion.

## Results

Accuracy is **our internal metric**: first visit to a seen node via a new directed edge,
in 4×4 and 8×8 worlds. Values below are regenerated by the report command from completed
records, with three training seeds per variant and 16,000 optimizer updates per seed.
The spread is sample standard deviation across training seeds.

| Variant | Accuracy, mean ± SD | Best baseline | Report verdict |
|---|---|---|---|
| v0 | 0.2358 ± 0.1499 | 0.1027 | FAIL |
| v1 | 0.7211 ± 0.0377 | 0.1027 | PASS (R2 claimed) |
| v2 | 0.7687 ± 0.0073 | 0.1027 | PASS (R2 claimed) |
| v3v0, rotation imposed | 0.8315 ± 0.0141 | 0.1027 | PASS (R2 claimed) |
| v3v1, rotation imposed | 0.7833 ± 0.0480 | 0.1027 | PASS (R2 claimed) |

“R2 claimed” is the report's coordinate-probe criterion, not a grid-cell classification.

## What this does and does not show

- Better than our earlier model (v0) and than the sensory-only/frequency baselines on our
  internal metric. NOT shown better than the paper: we did not score the authors' model on
  this metric. Their public-default code, run once for 40k iterations, stayed near chance
  in next-observation loss (about 2.1-2.5 against ln 10 = 2.30); ours reaches 1.0-1.15.
  Different code and worlds, one seed: indicative only. v0 is our reference-schedule
  implementation, not an authors' checkpoint.
- This metric is not comparable to the paper's gridness/remapping analyses.
- Gridness is not measurable at 8×8 under the library's resolution criterion.
- v3 builds in group structure, so periodicity there is imposed, not learned.
- Model weights were not saved, so no spatial-tuning comparison with the authors'
  checkpoint has been made yet; the supplied JSONs support behavioral aggregation only.
- Three seeds and small discrete worlds limit generalization; the spiking extension
  needs separate spatial and temporal validation.
