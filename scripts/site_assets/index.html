Spiking neural networks · HTM · Predictive coding

Neural circuits, written in PyTorch.

neuroSush is an open-source library for simulating spiking neurons, plastic synapses, HTM / Thousand Brains columns and predictive coding. Every model is tested against its equations.

Predictive coding

Predictions down, errors up.

Hierarchical predictive coding in which each level predicts the one below and learns from the residual. Tests check the update equations, not biological equivalence.

Library

Six decisions make a network.

Populations → Model → Learning → Inputs → Record → Run. The same six stages structure the Studio.

Define neuron groups and input sources with shape and configuration.

Python 
net = Network(seed=0)
source = NeuronGroup(net, 20, [SpikeInput(...), Axon()])
target = NeuronGroup(net, 2, [DendriteStructure(), LIF(...), Fire(), Axon()])

Choose neuron membrane dynamics and parameters (e.g. LIF, ELIF, AdEx, Izhikevich).

Python 
LIF(tau=10.0, threshold=-55.0, v_reset=-70.0, v_rest=-65.0, resistance=1.0)

Connect groups with synapses and add plasticity rules like STDP and weight clipping.

Python 
synapse = SynapseGroup(
    net, source, target,
    [WeightInit(mode="uniform", scale=0.5), DenseInput(coef=5.0), SpikeGather(), Traces(tau_pre=10.0), STDP(a_plus=0.02, a_minus=0.01, bound="soft"), WeightClip(w_min=0.0, w_max=1.0)]
)

Feed spike trains, Poisson rates, or sensory patterns into input groups.

Python 
train = rate_poisson(torch.full((20,), 0.3), 100, generator=net.generator)

Attach recorders to monitor spikes, voltages, weights, or traces during execution.

Python 
rec = Recorder("spikes")

Step through time or run batch simulations and inspect outputs.

Python 
for _ in range(200):
    net.step()
print(f"output spikes: {target.spikes.sum()}")
