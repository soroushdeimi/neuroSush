A FEW GOOD QUESTIONS

Know what
you're building on.

What is neuroSush?

A PyTorch library for spiking neural networks, HTM / Thousand Brains algorithms and hierarchical predictive coding. It is open source under the MIT license.

How does it relate to CoNeX?

neuroSush is a rewrite and superset of CoNeX, with explicit behavior ordering, pure equations and torch as its only runtime dependency. Treat it as a separate API; existing CoNeX code may need adaptation.

What does “validated” mean?

Tests compare equations with hand-computed values, exact solutions, closed-form probabilities and properties reported in the source papers on small setups. This is model-level validation, not a claim to reproduce a biological brain or every paper result.

Does everything run on the GPU?

No. Spiking networks support CPU and GPU. HTM and predictive coding run on CPU, one sample at a time; active dendrites also run on GPU. Graph and compiled steppers support specific behaviors and report incompatible ones.

Are the GUI and TEM available?

The no-code GUI is coming soon; the preview here is a design concept. Grid-cell modules are available today. TEM is a planned direction, not a shipped model.

Are the Atlas plates recorded experiments?

The shipped teaching plates run live JavaScript ports of the equations. Only the replay demo currently shows a recorded trace. The landing page artwork is illustrative; its LIF tuner runs the equation described beside it.
