Spiking neural networks · HTM · Predictive coding

Neural circuits, written in PyTorch.

neuroSush is an open-source library for simulating spiking neurons, plastic synapses, HTM / Thousand Brains columns and predictive coding. Every model is tested against its equations.

Synapses

Synapses that learn from spike timing.

Dense, sparse and delayed synapse groups, with STDP, triplet STDP, inhibitory STDP and dopamine-modulated reward learning.

Plate Y01 · STDP: who fired first?

Populations

From one cell to a population.

Neuron groups with LIF, ELIF, AdEx, Izhikevich and Hodgkin–Huxley dynamics, dendritic compartments, axonal delays, k-winners-take-all and homeostasis.

Balanced network example ↗

HTM / Thousand Brains

Sparse codes, columns that vote.

Spatial pooler, temporal memory with active dendrites, and Thousand Brains columns that settle on one object by lateral voting, alongside the spiking models.

Plate H01 · Sparse distributed representations

Predictive coding

Predictions down, errors up.

Hierarchical predictive coding in which each level predicts the one below and learns from the residual. Tests check the update equations, not biological equivalence.

Predictive coding example ↗

Space and memory

Grid cells and relational memory.

Grid-cell modules, rate maps and gridness scores are in the library. TEM models are in the library, not yet in a tagged release.

TEM is in development on main, not in v0.6.0. There is no live TEM demo here.
