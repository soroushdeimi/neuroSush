# Font sources

All families were downloaded from the official google/fonts repository on 2026-11-02.
Each adjacent licence was checked for SIL OPEN FONT LICENSE 1.1 before subsetting.

- https://github.com/google/fonts/tree/main/ofl/sourceserif4
- https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono
- https://github.com/google/fonts/tree/main/ofl/stixtwomath

Static instances: Source Serif optical sizes 60 (display) and 20 (semibold text);
IBM Plex Sans width 100, weights 400/500/600. FontTools instancer and subsetter,
WOFF2, hinting removed; Latin, used Greek variables, arrows and math operators.
Original families are unmodified upstream inputs; only these subsets ship.
No font is requested from a third party when viewing the site.
