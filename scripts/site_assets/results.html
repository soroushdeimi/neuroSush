01 / WHAT WE BUILT

Architecture & Components

neuroSush is a PyTorch library for spiking networks, HTM / Thousand Brains models and, new, a Tolman-Eichenbaum Machine (TEM, Whittington et al. 2020 Cell). TEM separates a cognitive map into reusable structure g (where am I on the graph) and sensory identity x (what do I see). Their conjunction p is stored in a fast Hebbian memory M that is reset per world, while the slow weights (transitions shared across worlds) are trained. Result: after seeing a node once, the model predicts it when reached through a NEW route in a NEW world. Code: src/neurosush/tem/, teaching note: docs/TEM.md ↗.

The ecosystem includes the PyTorch library, Atlas plate T01 (teaching visualization of Tolman-Eichenbaum Machine with imposed structure), and the Studio backend for project persistence, simulations, and validation.

02 / RESULTS OF OUR MODEL

Metric (ours, not the paper's): accuracy of predicting the observation on the first visit to an already-seen node through a new directed edge, in 4x4 and 8x8 graph worlds. 3 training seeds, 16,000 updates each. 03 / TRAINING STABILITY

The Four Fixes (v0 -> v1/v2)

  1. Missing L_p_x term and mis-scaled objective: Supervise sensory-cued memory, calibrate loss reductions.
  2. Reliability-blind fusion -> reliable_fusion: Weight memory correction by retrieval reliability.
  3. Unbounded attractor activation -> bounded activation: Prevents exploding gradients.
  4. Compressed memory curriculum: Gradual memory use.

These are implementation choices tested together, not four independently proven causes (v1 groups 1+3, v2 adds 2).

04 / EXTERNAL REPRODUCTION

The Authors' Public Code (Spiking TEM, Kawahara & Fujisawa 2025), One Run

Their TF2 code run in an isolated venv: 40k iterations, one seed, 8x8 worlds. Prediction loss stayed near chance for 10 labels (about 2.1-2.5, ln10 = 2.30). Our v1/v2 reach cross-entropy 1.15 / 1.01 (different code and worlds, indicative only). Spatial analysis of their checkpoint (our own scripts: reference-code/run-spikingtem/analysis/):

05 / SCIENTIFIC SCOPE

What We May and May Not Claim

May Say

  • A clean, tested TEM implementation that trains stably at reference-scale and clearly beats baselines on our internal metric.
  • Better than our earlier model (v0).
  • Their public-default run stayed near chance in prediction loss; ours does not (different code/worlds, one seed).

May NOT Say

  • "Better than the paper" (we never scored their model on our metric; no remapping/gridness comparison).
  • "Grid cells emerged" (periodicity in v3 is structure imposed; gridness is unresolved at 8x8; grid-cell emergence not shown).
  • Theta phase precession as emergent (theta is imposed).
  • Any number not in section 2 or 3.
