Results & Reproducibility

Clean tested TEM implementation that trains stably at reference-scale and clearly beats baselines on our internal metric; grid-cell emergence not shown.

Last updated: 2026-11-02. Every number below comes from a run or file named in the source report (docs/RESULTS.md ↗). Rule: nothing goes on the site or in a PR unless it is supported by the findings with its caveat.

01 / WHAT WE BUILT

Architecture & Components

neuroSush is a PyTorch library for spiking networks, HTM / Thousand Brains models and, new, a Tolman-Eichenbaum Machine (TEM, Whittington et al. 2020 Cell). TEM separates a cognitive map into reusable structure g (where am I on the graph) and sensory identity x (what do I see). Their conjunction p is stored in a fast Hebbian memory M that is reset per world, while the slow weights (transitions shared across worlds) are trained. Result: after seeing a node once, the model predicts it when reached through a NEW route in a NEW world. Code: src/neurosush/tem/, teaching note: docs/TEM.md ↗.

The ecosystem includes the PyTorch library, Atlas plate T01 (teaching visualization of Tolman-Eichenbaum Machine with imposed structure), and the Studio backend for project persistence, simulations, and validation.

03 / TRAINING STABILITY

The Four Fixes (v0 -> v1/v2)

  1. Missing L_p_x term and mis-scaled objective: Supervise sensory-cued memory, calibrate loss reductions.
  2. Reliability-blind fusion -> reliable_fusion: Weight memory correction by retrieval reliability.
  3. Unbounded attractor activation -> bounded activation: Prevents exploding gradients.
  4. Compressed memory curriculum: Gradual memory use.

These are implementation choices tested together, not four independently proven causes (v1 groups 1+3, v2 adds 2).

Their TF2 code run in an isolated venv: 40k iterations, one seed, 8x8 worlds. Prediction loss stayed near chance for 10 labels (about 2.1-2.5, ln10 = 2.30). Reading:

  • Position can be decoded within a world from g and from p (well above the shift null).
  • Audit note (2026-11-02): this is not evidence of a world-independent position code. Cross-world RSA of g is 0.74 (v2) and 0.83 (v1), but the null (p95 about 0.04) is weak: an untrained path integrator with random transition weights already scores 0.13-0.20, and trained transitions without memory score 0.17 (v1) and 0.49 (v2). Displacement alone explains 91-95% of within-world distance variance, so g mostly path-integrates coherently with a world-specific phase. The margin of the full model over path integration alone is real but smaller (about 0.25 for v2). The earlier random-init control (0.07) was degenerate. The authors' public run showed about 0 on this measure; different code, worlds and training, so not a ranking against the paper.
  • It does not follow Manhattan grid distance (RSA vs grid about 0) nor sensory identity, and it does not show grid cells. Control experiments and metric tests are planned before any stronger statement.
  • p mainly follows sensory identity (RSA vs sensory 0.63 and 0.73), as in the authors' run, and its map correlation across worlds is near zero.
  • Random-init p also decodes position (0.54) because the fast memory binds observations within a world: high within-world decoding alone is not evidence of learned geometry.
  • Spatial information of g and g_gen is about 1e12 because the reference formula accepts signed activations: a diagnostic, not bits per spike. Only p has a usable-looking value.
  • One seed per model, 8x8 worlds: gridness is not resolvable. Needs seeds 1-2 and 16x16 worlds before any stronger statement.

06 / SCIENTIFIC SCOPE

What We May and May Not Claim

May Say

  • A clean, tested TEM implementation that trains stably at reference-scale and clearly beats baselines on our internal metric.
  • Better than our earlier model (v0).
  • Their public-default run stayed near chance in prediction loss; ours does not (different code/worlds, one seed).

May NOT Say

  • "Better than the paper" (we never scored their model on our metric; no remapping/gridness comparison).
  • "Grid cells emerged" (periodicity in v3 is structure imposed; gridness is unresolved at 8x8; grid-cell emergence not shown).
  • Theta phase precession as emergent (theta is imposed).
  • Any number not in section 2 or 3.
