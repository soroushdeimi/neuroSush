# neuroSush mark studies

Open `preview.html` to compare the marks at 16, 32, 64 and 256 px in both themes.
`preview.png` records the same page in Chrome, including the Source Serif 4 header.

- **A · Apical:** an organic soma with four dendrites and a short axon.
  The most literal neuron; its fine stem is less robust at 16 px.
- **B · Passage:** a travelling spike between two separated curved branches.
  A distinctive horizontal mark; the central gap becomes subtle at 16 px.
- **C · Arbor:** four open branch terminals above a broad curved arbor.
  Recommended for its balanced silhouette, open spaces and strong small-size reading.

Each candidate has `dark/` and `light/` exports:

- `mark-512.png`, `mark-180.png`, `mark-32.png`, `mark-16.png`: opaque square tiles.
- `transparent-512.png`: the same silhouette with a transparent background.
- `favicon.ico`: embedded 16 px and 32 px frames.

Dark tiles use amber `#F2B33D` on `#0D0E0E`. Light tiles use graphite
`#1A1A17` on warm paper `#F4F1EA`. Edge pixels are antialiased; the smallest
exports receive a slight coverage adjustment to preserve thin strokes.
All PNGs contain image data only, with no metadata or text chunks.

No tracing program was available, so this set contains raster exports only.
These are review candidates; the existing site branding is unchanged.
