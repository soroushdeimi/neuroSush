# Template LIF Neuron

## What it teaches
Demonstrates the Leaky Integrate-and-Fire (LIF) membrane potential derivative equation: $\tau \frac{dv}{dt} = (v_{rest} - v) + R I$.

## References
- Gerstner, W., & Kistler, W. M. (2002). Spiking Neuron Models. Cambridge University Press.

## Simplifications
Single compartment point neuron with constant leak and input resistance.
